About Sprout

A playful place to learn by making.

Sprout is a small creative coding demo inspired by block-based programming. It gives curious makers a visual way to experiment with motion, messages, and sprites.

Make a project

Choose blocks, arrange a short script, and see your idea move on the stage.

Start from an idea

Remix one of the sample projects, then change the sprite or its script.

Keep creating

Projects are saved locally in this browser. Export a JSON file to keep a separate copy.

Community guidelines

This demo runs locally and has no public sharing service. Be kind, make original projects, and get permission before sharing someone else’s work.

Help center

In the editor, choose a block category, click blocks to add them, then press the green flag. Use the blue stop button to stop the script.

Privacy

Your project data stays in this browser’s local storage unless you choose to download its JSON export. There is no account system or server connected to this demo.
